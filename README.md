# MySiteHtmlOnly
На каждой странице находится меню из четырех пунктов:
1. Главная - ведет на главную страницу.
2. Сравнение с 13 Pro - ведет на главную страницу и перемещает страницу к таблице сравнения.
3. Отзывы - открывает вторую страницу с отзывами.
4. Заказать - ведет на страницу с формой заказа.

На первой странице должны располагаться заголовок, картинка телефона шириной 250 пикселей, характеристики и сравнительная таблица телефонов.
На второй странице будет заголовок и отзывы об этом мобильном телефоне.
На третьей странице должна быть форма заказа.
Поля в форме:
Имя: текстовое, обязательное
Фамилия: текстовое, обязательное
Телефон, состоит из 2 полей:
- поле выбора кода города: выпадающий список (варианты: +375, +7, +380), обязательное
- номер телефона: текстовое, обязательное
Email: текстовое поле с типом email (проверить как работает), обязательное
Объем памяти: выпадающий список (варианты: 64, 256, 512)
Способ доставки: переключатель (radio), обязательное
Добавить к заказу: чекбоксы, необязательное
Комментарий: многострочный текст, необязательное
Принимаю условия сайта: чекбокс и текст (слова «Условия сайта» - ссылка на любой сайт)

Важные моменты выполнения домашки:
При создании необходимо использовать семантические теги: header, nav, main, footer.
Элементы формы должны быть оформлены с label. Каждый новый элемент/группа - с новой строки. Соответственно, элементы переключатели (checkbox, radio) должны выбираться не только по нажатию на сам элемент, но и на сопутствующий текст этого значения.
Форма должна отправлять запрос методом POST. При выполнении ОБЯЗАТЕЛЬНО отправьте форму на сайт получения данных и проверьте, чтобы все данные приходили! (Каждый элемент работы с данными должен иметь name для этого)
